registration-form1 works using Template Driven Forms!

Product Details Form

#productForm is template reference variable for the ngForm directive, that governs the form

Angular contains validation classes

  • .ng-valid: Applied when the form control is valid.
  • .ng-invalid: Applied when the form control is invalid.
  • .ng-touched: Applied when the form control has been touched (focused and then blurred).
  • .ng-untouched: Applied when the form control has not been touched.
  • .ng-dirty: Applied when the form control's value has been changed.
  • .ng-pristine: Applied when the form control's value has not been changed

To include error messages, we can use the following code snippet for each form control:

@if(name.errors?.['required'] && name.touched) { Name is required. } @if((name.errors?.['minlength'] || name.errors?.['maxlength']) && name.touched) { Name must be between 3 and 20 characters. }

@if(price.errors?.['required'] && price.touched) { Price is required. } @if(price.errors?.['min'] && price.touched) { Price must be at least 1000. }

@if(description.errors?.['required'] && description.touched) { Description is required. }

@if(stock.errors?.['required'] && stock.touched) { Stock is required. } @if(stock.errors?.['min'] && stock.touched) { Stock must be at least 5. }
